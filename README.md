# bodian · Loon 自用

波点音乐每日任务 Loon 插件:**每日签到 + 听歌奖励 + 惊喜宝箱 + 免费抽奖 + 吃饭领金币**,支持多账号。

## 导入

Loon → 配置 → 插件 → `+` → 从 URL 下载:

```
https://raw.githubusercontent.com/chen-arch8/bodian/main/bodian.lpx
```

需要 Loon 3.5+,导入后同意安装 MITM 证书并打开 MITM 总开关(`bd-api.kuwo.cn` 由插件自动追加)。

## 使用

1. **取凭据**:确认「抓取凭据」开关开着 → 打开波点音乐 App →「赚钱(金币)」页面,收到「✅ 获取凭据成功」即完成 → **把开关关掉**(开关直接停用拦截规则,插件脚本列表里「波点音乐凭据」会显示未启用,App 请求完全不受影响)
2. **自动运行**:每天 8:00 / 13:00 / 19:00 / 22:00(覆盖四个饭点 + 宝箱冷却)
3. **手动运行**:Loon → 配置 → 脚本(或插件详情页脚本列表)→ 点进「波点音乐任务」→ 右上角 ▶ 运行,战报在脚本日志和通知里
4. **凭据失效**:通知出现「登录失效」后,先打开「抓取凭据」开关,再重新打开赚钱页划一下,收到「✅ 更新凭据成功」即恢复,然后记得再关掉开关

## 插件参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 抓取凭据 | 开 | **抓完就关**;关闭后拦截规则整体停用,失效重抓时再打开 |
| 免费抽奖 | 开 | 每日免费次数抽完即停,看广告的不做 |
| 吃饭领金币 | 开 | 领当前饭点 + 连吃奖励,错过需看广告补领的不做 |
| 宝箱尝试次数 | 3 | 1~5,宝箱有冷却,配合一天多次定时能多开 |
| 调试模式 | 关 | 开启后每次 API 响应原文写入脚本日志,排查「登录失效」等问题用,平时不用开 |
| 清除凭据 | 关 | 下次运行清空全部已存账号 |

## 任务明细

- 每日签到:周期第 N 天对应卡片,+188 金币起,记录连续天数
- 听歌奖励:自动领取已达标档位(5/60/300/600/1200/1800/3600/7200/10800 分钟),听歌时长需 App 真实听歌累计,脚本只负责到点就领
- 惊喜宝箱:有冷却,每次运行最多开「宝箱尝试次数」个
- 每日抽奖:每天 1 次免费,其余需看广告(跳过)
- 吃饭赚金币:05-09 早餐 / 10-15 午餐 / 16-20 晚餐 / 21-24 夜宵,+50 金币/餐 + 连吃奖励

## 接口说明(排查用)

- 域名 `bd-api.kuwo.cn`,鉴权只要 `uid` + `token` + 请求头 `payload`
- 签到状态:`GET /api/advert/earning/h5/task/info?taskType=sign` → `todaySign`
- 全部任务走 `POST /api/advert/earning/h5/doTask`,`taskType` 区分:
  `sign` / `listen` / `floatBox` / `dailyLottery(type:free)` / `dineEarnMoney(dineCheckIn+conDine)`
- 听歌档位状态:`GET /api/advert/earning/h5/task/info?taskType=listen` → `status: 3=可领, 2=未达标, 1=已领`
- `kwflag` 服务端不校验;缺 `payload` 头会报「登录失效」
- 摇钱树小游戏需要 `x-gopen-sign` 动态签名,无法离线复现,未包含
